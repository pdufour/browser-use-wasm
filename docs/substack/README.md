# Substack tutorial (browser-use)

Draft assets for a **generic** browser-use article — separate from the [Gemini Nano demo](../../examples/gemma-nano/).

## Pipeline diagram

With the dev server already running:

```bash
npm run dev
```

Open **http://127.0.0.1:5173/substack/** → **Download PNG (2×)** exports the full card (title + diagram + tags).

Mermaid is bundled from `node_modules` (COEP-safe on the main dev server).
